# UI Kit — Espace établissement

Dark-sidebar back-office for a school managing its own listing.

- **index.html** — Tableau de bord: SidebarNav (theme `etablissement`), KPI StatCards, BarChart (monthly views) + SourceBars (contact origin), latest RequestCards, and a navy credits panel with ProgressBar + recharge CTA.

Composes: `SidebarNav`, `StatCard`, `BarChart`, `SourceBars`, `RequestCard`, `ProgressBar`, `Button`, `Badge`.

Greeting pattern "Bonjour, Sara 👋". Active sidebar item is solid red; counters as red badges.
