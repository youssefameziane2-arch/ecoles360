Social/contact channel chips for a profile.

```jsx
<SocialLinks links={[
  {type:'whatsapp', href:'…'},
  {type:'phone', href:'tel:…'},
  {type:'website', href:'…'},
  {type:'instagram', href:'…'},
]} />
```

Known `type`s set glyph + color; pass `glyph`/`label` for a custom channel. WhatsApp keeps its green treatment.
