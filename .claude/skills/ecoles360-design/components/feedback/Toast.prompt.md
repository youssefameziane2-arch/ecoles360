Transient notification. Tones: success / error / info / warning.

```jsx
<Toast tone="success" title="Demande envoyée" message="L'établissement vous répondra sous 48 h." onClose={…} />
<Toast tone="error" title="Échec du paiement" message="Vérifiez votre carte." onClose={…} />
```

Stack several in a fixed top-right column. Manage visibility/auto-dismiss in the host.
