Dashboard KPI card. Big numeral + label + delta + icon chip.

```jsx
<StatCard label="Vues ce mois" value="8 420" delta="12%" deltaDir="up" icon="👁" tone="navy" />
<StatCard label="Crédits restants" value="320" delta="8%" deltaDir="down" icon="💳" tone="red" />
```

Delta green for up, red for down. Numbers use thin-space thousands separators.
