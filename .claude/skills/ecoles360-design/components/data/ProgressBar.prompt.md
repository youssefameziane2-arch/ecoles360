Flat gauge bar. Use for the credits balance, profile completeness, and rating-distribution rows.

```jsx
<ProgressBar label="Solde de crédits" value={320} max={500} showValue />
<ProgressBar value={4.8} max={5} tone="amber" height={6} />
```

Tones: red, navy, green, amber. Track is the sunken surface; fill animates on change.
